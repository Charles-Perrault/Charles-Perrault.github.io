# Charles-Perrault.github.io

Tony Eagle uses the recovered original Unity game and music. The shared leaderboard
appears as Leaderboard.txt in Notepad. Scores are frozen at round end; the Konami
code unlocks unlimited upgrades and disqualifies the run. Saved cheat upgrades
remain excluded until Reset upgrades clears them.

The score API and D1 database are hosted with Sites at
https://tony-eagle-leaderboard.new-plum-8104.chatgpt.site
(project `appgprj_6ad29be35e9c819189029d30ad9119d5`). The GitHub Pages frontend has
no server secrets. The backend rejects marked cheat runs, duplicate submissions,
and scores submitted before a full round could have elapsed.

Bench Press Study text comes from Charlie's Google Doc through study-document.js.
Use Edit in Google Docs in the study toolbar. The manuscript refreshes when opened
and every five minutes while visible, with a sanitized cached/offline fallback.
Keep a Results section for the live Google Sheets statistics and chart. The Word
download refreshes both sources and exports the same displayed manuscript and data.
